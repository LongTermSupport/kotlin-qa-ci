# Defence Before Fix conformance

Status: **partial**. This toolchain does not claim conformance. The machine-readable declaration
is `[tool.defence-before-fix]` in `pyproject.toml`; this page is the evidence record, with every
gap stated.

Specifications: method 1.1.0, detector 1.0.0, toolchain 0.2.0
(https://defence-before-fix.github.io/).

| 4.1     | Every detector a defence is routed through conforms                                                | Gap         | Bespoke Kotlin defences are routed through Semgrep, run with `--disable-nosem` and a pinned version, and proved by `kqaci.rules.unproved` against adjacent fixtures. Semgrep patterns are syntactic: a rule cannot see types or resolved calls. ktlint, Detekt and Android Lint run off-the-shelf as blocking checks and cannot host a bespoke rule without a built jar, so a bespoke rule that needs types is not yet possible                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 4.2     | Every printable identifier resolves offline; pages state the correct construction                  | Partial     | `kotlin-qa rule-doc`: bundled pages (each with a "How to fix correctly" section, enforced by `tests/kotlin_qa/test_release_gate.py`), the project's pages under `docs_dir` (enforced by `kqaci.docs.dangling`), each project check's own `doc`. ktlint and Android Lint identifiers resolve only to a route page naming the tool; their own catalogues are not bundled                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 4.3     | A defence forbids every suppression route that bypasses the record                                 | Partial     | `kqaci.suppression.unrecorded` and `.blanket` cover `@Suppress`, `@SuppressWarnings`, `@SuppressLint`, ktlint disable comments in all spellings, `noinspection`, `nosemgrep`, `tools:ignore`, `tools:suppress`, `lint.xml` severity ignore, a Lint baseline file, loosening Gradle `lint {}` settings, Kotlin `suppressWarnings`, `.editorconfig` ktlint rule disabling, and the tool's own `tools.*` and `scan_exclude` switches. Since 0.2.0 also: `@Suppress("detekt:...")` and `detekt.` forms, a Detekt baseline file, `ignoreFailures = true`, `allWarningsAsErrors = false`, `# shellcheck disable=`, `gitleaks:allow`, `.gitleaksignore`, `# zizmor: ignore`, and `ignore:` in the actionlint and zizmor configuration; a loosened rule in `qa/detekt.yml` fails `kqaci.detekt.unjustified` unless it carries a reason. Not covered: a suppression made through a typealias or a custom annotation, a bare `@Suppress("RuleName")` is routed as `kotlin::RuleName` rather than to Detekt, and compiler flags other than `suppressWarnings` and `allWarningsAsErrors` |
